# Reclaim-Time-Off-Screen-Tracker
Track Less of What Distracts You. Celebrate What Resets You.

Unlike traditional screen-time trackers that measure only how long you stay online, this app flips the narrative:  It highlights how long you've been offline, idle, or consciously away from your device.


Hello, and welcome to our GitHub repository! Whether you want to download and run the app straight away or tinker with the raw code, we’ve got you covered.

🚀 How to Run the App
Option 1: Download the .exe File
- Step 1: Download the .exe from the main page of this repository.
- Step 2: Run the .exe file on your Windows device.
- Important: Windows security might flag the file. This is normal for new .exe files—rest assured, it's part of our MVP stage. You can safely ignore the warning.
